How Beleg works

The full app prepares a record for a human reviewer. This site replays sample results in your browser, without a server or API key.

Read the architecture

  1. Text extraction and translation

    Extract text from PDFs or scans, identify key fields, and keep a German translation alongside the original.

  2. Currency conversion

    Apply a historical exchange rate with decimal arithmetic. Missing dates or currencies stop the conversion.

  3. Human review

    LangGraph saves progress and pauses so a reviewer can check the suggested category against the source.

  4. Record export

    After approval, the local app exports a structured CSV or JSON file.
